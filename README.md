# AdventureWorks SQL Practice

## Introduction
A set of T-SQL query exercises on Microsoft's **AdventureWorks2019** sample database. It progresses from basic filtering to joins, aggregation, subqueries, and business-style reporting queries.

![T-SQL](https://img.shields.io/badge/T--SQL-CC2927?style=flat&logo=microsoftsqlserver&logoColor=white)

## Contents
| Files | Topic |
|---|---|
| `01.sql` – `05.sql` | Exercise sets that progress in difficulty |
| `practice01.sql` – `practice04.sql` | Additional practice queries |
| `AdventureWorks.pdf` | Schema reference |

## How to run
1. Download and restore [AdventureWorks2019](https://learn.microsoft.com/sql/samples/adventureworks-install-configure) in SQL Server.
2. Open any `.sql` file in SSMS and execute it.

## Skills
SELECT and filtering · joins across sales, product, and person schemas · GROUP BY / HAVING · subqueries and CTEs
